# Supplementary Video Materials

Manuscript title:
Model based design and transmission analysis of multisection rod driven continuum robots using Cosserat rod theory

These videos provide supplementary visual material for the numerical simulations associated with the project. They are not experimental videos. They illustrate simulated robot motion, drive routing, planning versus replay behavior, and multisection 9/6/3 routing cases used to support mechanism modeling and quasi static numerical validation.

## Core videos

The folder `videos/core_videos` contains the main video set. These files are aligned with the main numerical cases.

| File | Purpose | Project connection |
|---|---|---|
| `S1_single_section_coupled_vs_uncoupled_comparison.mp4` | Visual check of the single-section boundary case and planning/replay contrast. | Auxiliary single-section validation and supplementary boundary check. |
| `S2_two_section_standard_spatial_circle_robot_with_disks.mp4` | Standard two-section spatial-circle simulation with disked rod routing. | Two-section 6/3 planning-side transmission validation. |
| `S3_two_section_large_deformation_robot_with_disks.mp4` | Enlarged two-section spatial-circle motion with larger deformation. | Large-deformation two-section planning-side validation. |
| `S4_two_section_incremental_equilibrium_replay_comparison.mp4` | Planning-versus-incremental-equilibrium replay comparison for the two-section large-deformation command. | Command-to-equilibrium replay and quasi-static consistency analysis. |
| `S5_three_section_9_6_3_spatial_circle_robot_with_disks.mp4` | Three-section nested 9/6/3 routing under a spatial-circle command. | Multisection nested-routing extension. |
| `S6_three_section_9_6_3_chinese_knot_robot_with_disks.mp4` | Three-section nested 9/6/3 Chinese-knot trajectory with disked structure. | Main three-section complex-trajectory numerical assessment. |

## Suggested public description

The videos illustrate numerical simulation results and the corresponding rod routing geometry. They show the single section auxiliary case, the two section 6/3 routing cases, planning versus incremental equilibrium replay behavior, and three section 9/6/3 nested routing examples. The videos should be interpreted as supplementary numerical material rather than experimental validation.

## File format

All videos are provided in MP4 format. The file names are prefixed with `S` for the core set and `O` for optional context videos.
