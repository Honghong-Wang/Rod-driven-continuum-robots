# Public Release Policy

Developer: HH  
Affiliation: Fuyang Normal University, China

## Publicly released materials

This public repository includes selected media and compact result data:

- Simulation videos in MP4 format.
- Aggregate CSV result tables.
- Documentation and file manifests.

These files are suitable for public viewing, project demonstration, and high level result inspection.

## Materials outside this release

The following materials are outside the scope of this media and summary data package:

- MATLAB source code, including `.m`, `.mlx`, and launcher files.
- Raw MATLAB workspaces, including `.mat` files.
- Internal simulation checkpoints.
- Full design of experiment scripts.
- Incremental equilibrium replay solver implementation.
- Analytical Jacobian and tangent stiffness implementation details.

Executable modeling code, if released, will be distributed separately.

## Current public release principle

The package supports visual inspection and aggregate data checking while keeping this repository focused on media and summary results.
