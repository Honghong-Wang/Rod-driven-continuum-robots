## Videos

The `videos/` folder contains MP4 files showing selected numerical simulation cases for rod driven continuum robots. The videos include one section, two section, and three section cases, with emphasis on routing architecture, large deformation motion, and three section 9/6/3 motion examples.

The file `videos/video_manifest.csv` lists the video filenames and their short descriptions.

## Summary CSV data

The `data/summary_csv/` folder contains compact result tables exported from the numerical simulation workflow. These tables report aggregate quantities such as error metrics, drive load summaries, design screening metrics, perturbation checks, and comparison data.

The CSV files are provided for result inspection and plotting. They are not intended to serve as a full executable reproduction package.

## Units

The CSV files retain the units used in their column names where applicable, for example millimeters for displacement and error, newtons for force, and dimensionless values for normalized constraints or condition metrics.
